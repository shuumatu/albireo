## 1. 推荐方向

**影像档案 / Personal Visual Archive**

用摄影作品建立情绪，用明日方舟式的网格、编号、信息层级与硬边控件建立识别度。网站仍然是一个方便浏览照片、视频和旅途的个人影像网站。

第一眼看到作品和作者表达；第二眼看清“浏览作品、按时间找、按地点找”；进入内容后，界面安静地退到作品周围。

- 主视觉：炭黑、雾白、青蓝，保留第一版的摄影展示气质和照片原始色彩。
- 形状：直角为主，少量 8px 切角用于主按钮；1px 细线分隔。
- 排版：中文大标题；英文小标签和等宽编号作辅助。
- 结构：强主次、非对称构图、明确的章节入口。
- 交互：保留首页底部悬停切图，入口改为分段刻度；补充触摸点击和键盘聚焦；自然滚动、短过渡。
- 品牌：预览暂用项目已有名称 ALBIREO。正式落地时保留现有个人签名作为作者标识，统一页头、页脚与分享页的命名；不将示例 A 字标视为最终 Logo。

**具体取舍：**

1. 保留第一版黑白灰与青蓝配色；HUD 通过几何、细线、信息层级和空间叠层融入现有风格。
2. 摄影作品保留彩色。灰度用于界面外壳，不给作品统一套滤镜。
3. 首页可以具有展示感；时间线、搜索和评论区优先保障阅读与操作。
4. 正文采用自然滚动。全屏地图是专门布局；不把全站做成强制逐屏滚动。
5. 装饰优先放在边缘、标题、分组及交互反馈位置。图像本身保持清晰，所有页面均不叠加 CRT 扫描线或屏幕畸变。真实日期、地点、类型等才进入作品信息区。
6. 以已有摄影资产和原创界面图形落地，保持个人网站自己的内容与品牌。

## 4. 视觉规范

### 4.1 色彩与材质

以下是本项目建议值，不是从官网提取的官方色值。

| 变量 | 色值 | 使用位置 |
| --- | --- | --- |
| `--color-bg` | `#101416` | 全站深色底、页头 |
| `--color-surface` | `#1B2226` | 深色浮层、输入和信息区 |
| `--color-text` | `#EDF0ED` | 深底主文字 |
| `--color-muted` | `#A4AFB3` | 深底次级文字 |
| `--color-line` | `#384145` | 非交互性结构线 |
| `--color-accent` | `#64C7E1` | 主 CTA、焦点、当前作品、选中点与少量 HUD 标记 |
| `--color-accent-ink` | `#102026` | 青蓝按钮内的深色文字 |
| `--color-paper` | `#E5E8E5` | 首页精选内容带，可选浅色档案区 |
| `--color-paper-ink` | `#172126` | 浅色区主文字 |
| `--color-paper-muted` | `#526970` | 浅色区次级文字 |

状态另设成功、警告、错误色，配合图标与文字，不与媒体类型配色混用。按钮、输入、滑块的边界与焦点需要单独验证对比度；不能直接沿用较暗的装饰线。

照片上文字使用局部渐变遮罩。普通信息面板采用接近不透明的底色；模糊只保留在必要的全屏预览遮罩。

### 4.2 字体与空间

- 中文：系统无衬线优先，后续可引入经过子集化的思源黑体；不阻塞首屏等字体。
- 英文标题：紧凑粗体无衬线；数据、时间、编号用等宽体。
- 首页图片名：桌面 21px、手机 19px；当前张数：桌面 48px、手机 36px，使用青蓝粗体；下方内容区主标题：桌面 40–48px、手机 30–34px；正文 14–16px、行高 1.6–1.8。
- 操作文字：桌面 14px、手机至少 14px；辅助标签 11–12px；8–10px 只允许用于不承载操作含义的装饰英文。概念稿的小标签在生产迁移时按此约束收紧。
- 桌面 12 列栅格，内容最大宽度 1440px，页边距 40–80px；手机 20–24px。
- 间距基于 4px 倍数：8 / 12 / 16 / 24 / 32 / 48 / 64。
- 卡片直角或 2px 微圆角；头像可圆形；切角只用于少量高优先级组件。

### 4.3 动效

| 场景 | 设计 |
| --- | --- |
| 按钮、导航 hover/focus | 120–180ms 颜色与底线变化 |
| 作品卡片 hover | 180–240ms 角标出现，图片最多放大到 1.025；文字始终可见 |
| 首屏悬停切图 | 底部分段刻度：mouseenter / pointerenter 即请求切换，250–350ms 交叉淡化；聚焦和点击走同一逻辑；目标图就绪后提交，只显示最后一次请求 |
| 详情、抽屉展开 | 180–240ms，8–12px 位移；关闭后恢复焦点 |
| 图片逐渐显示 | 用真实加载状态驱动，不显示虚假加载进度 |
| 降低动态效果 | `prefers-reduced-motion` 下关闭视差、缩放、渐入与平滑滚动 |

首期不自动轮播、不默认播放声音。避免同时运行多套动效库；先用 CSS，复杂动画再复用项目已有能力。

### 4.4 HUD / 点线面具体落点（修订 04）

**首页图片区保持纯净；内容区用几何标记、分组标题与信息面板建立层次。** 装饰不拦截点击，不进入键盘顺序和读屏内容。没有扫描线、噪点、屏幕曲面或绿黄复古滤镜。

| 位置 | 点 | 线 | 面与层次 | 强度 |
| --- | --- | --- | --- | --- |
| 首页图片展示区 | 小刻度标示每一项的位置 | 5 段向右倾斜的平行刻度，当前项展开为青蓝斜块 | 档案式图片名 + 青蓝当前张数 + SCROLL TO EXPLORE 向下入口；底部轻渐变保证可读性 | 低，装饰集中在底部，主体保持开阔 |
| 首页下方章节区 | 章节标签前小方点、单个十字 | 低对比断环、章节分隔线、局部短刻度 | 主标题与固定章节编号 01 组织精选内容 | 低到中；手机收起断环 |
| 作品列表与推荐卡片 | 标题前小方点 | 日期基线、悬停时出现的两角标记 | 封面 → 标签条 → 轻量角标 | 低，避免每张卡片都有复杂边框 |
| 时间线 | 真实日期节点、当前位置 | 年月刻度、细竖线、短连接线 | 当前日期小色块，作品按真实日期分组 | 中，装饰同时承担导航 |
| 地图 | 真实点位或聚合点，当前点青蓝 | 实际轨迹/范围、选中圈、边缘刻度 | 浮层列表、定位工具、作品预览构成深度 | 中，HUD 与地理信息直接对应 |
| 详情页 | 少量元数据标记 | 信息区分隔线、角标、底部短刻度 | 干净的图片舞台 + 独立档案侧栏 | 低 |
| 搜索 / 登录 | 输入焦点、真实状态指示 | 输入框端点、结果分隔线 | 简洁输入面板 | 低 |

**悬停切换器的保留规则：**

1. 五条分段刻度与青蓝当前张数（01 / 05）组成切换区；移到具体刻度就切背景，无需先点击。底部另保留 SCROLL TO EXPLORE 等宽文字与向下箭头，点击进入精选区。
2. 悬停时斜线在固定操作区内变宽；当前项使用青蓝平行四边形与下划线，选中状态不只依靠颜色区分。图片名、FEATURED 编号、当前张数和选中状态同步变化。下方章节编号为固定分组标识，不随图片变化。
3. 鼠标离开后保留最后选择；快速扫过多个刻度时，取消过期结果，避免异步图片加载把画面切回旧选择。
4. 手机轻触，键盘 Tab 聚焦也可切换。44×44px 命中区包住每段刻度；读屏获得作品名称和选中状态。
5. 不增加自动轮播、闪屏或循环故障效果；减少动态效果时直接切换。

**照片显示：**保留初版的大图和自然色彩；仅底部小范围使用渐变，保障图片名与操作可读。首屏不叠加大标题、按钮、HUD 边框、断环、侧边字、基准线和标尺。详情图片和视频呈现原有比例与清晰度。

**一致性约束：**

- 同一区块只选一组主装饰（角标 / 刻度 / 断环），辅助装饰控制在边缘；中间的作品主体留出连续空间。
- 青蓝只强调当前选择、主操作和少量关键节点，正文继续用白灰。
- 内容区线宽以 1px 为主，装饰线比文字更低对比；手机收起断环。首页图片区在所有宽度下保留图片名、分段切换器、张数与 SCROLL TO EXPLORE；手机将图片名和向下入口放在同一行，切换器与张数放在下一行。
- 装饰不模拟虚假的 GPS、时间、网络速率或系统告警。编号只表达当前画面或真实分组。
- HUD 默认静态，操作只触发短过渡，不让断环持续旋转。装饰层 `pointer-events:none`、`aria-hidden=true`。

以上位置和强度是针对 Albireo 的设计建议，以用户最新确认的初版整体风格为基础。

## 5. 页面设计

### 5.1 首页 `/`

从上到下：

1. **统一导航**：个人品牌 / 首页 / 时间线 / 地图 / 搜索 / 登录或个人入口。中文是主标签，英文是辅助标签。
2. **图片首屏**：大幅照片 + 图片名 + 底部悬停分段切换器 + 当前张数（01 / 05）+ SCROLL TO EXPLORE 向下入口。入口保留等宽字和箭头，点击定位精选区；不放大标题、面板或装饰边框；悬停、触摸和键盘沿用同一切换逻辑。
3. **精选影像**：作者表达移到此处，断环章节号、细分隔线与短刻度只出现在内容区；提供时间线入口。一张主作品配两张次作品，使用现有 featured 推荐接口。
4. **旅途回忆**：封面、真实地点、时间段、作品数，沿用现有 bbox + 日期跳转地图的能力。
5. **热门作品**：紧凑列表或网格；保留原有 hot 接口，推荐次序为精选 → 旅途 → 热门。
6. **页脚**：个人签名、简短说明、版权信息。

首期首页选择逻辑：用 existing featured 结果取最多 3–5 张可用封面；无数据时用本地照片作不带伪造元数据的视觉封面，并提供通往时间线的入口。若要人工维护首屏文案、排序与焦点位置，另列内容配置任务，不假定已有后端字段。

### 5.2 图片详情 `/image/:uuid`

- 桌面：约 70% 宽度为纯净图片舞台，右侧 280–340px 为档案信息；评论与相似推荐在下方。
- 图片默认完整显示、保持比例。全屏预览再提供缩放，避免图片被装饰边框裁切。
- 信息优先：标题 → 描述 → 拍摄时间 → 标签/类型 → 可用的公开地点信息。技术字段、内部处理状态和文件名退到可折叠详情，普通访客不优先看到。
- 当前 `ImageInfoVO` 未提供相机、镜头、ISO、GPS 等完整 EXIF 字段。没有数据就隐藏相应行，不把示例 EXIF 变成前端假数据。
- 全屏预览支持 Esc、键盘焦点限制、关闭后焦点恢复；同一列表上下张切换仅在可获得列表上下文时启用。
- 图片加载失败提供重试、返回与文本说明。

预览中的弹窗演示的是图片舞台与信息面板；正式版保留可直接访问、可分享的详情 URL。

### 5.3 视频详情 `/video/:uuid`

- 播放器与图片舞台共享背景、边距及标题层级。
- 保留现有 VideoPlayer 的原画、多码率、封面和播放控制能力。
- 标题、日期、标签、简介移入统一的作品信息组件。
- 播放控件在触摸设备上可明确唤出；保持全屏、音量、键盘操作和错误提示。
- 播放期间避免不必要的背景动画；相似推荐和评论采用统一样式。

### 5.4 时间线 `/timeline`

- 桌面左侧为年份/月索引，右侧为日期分组图片流；当前日期清晰高亮。
- 保留已有按需加载、日期统计、占位高度估算；先重排外观，再逐步替换需要调整的索引交互。
- 日期定位支持点击与键盘；拖动仅作补充能力。
- 手机用顶部日期选择与分组标题，取代狭窄的侧边刻度。
- 离开详情返回时恢复原日期、滚动位置和筛选条件。
- 概念预览使用“夜色/冬日”示例分组说明版式，生产版仍使用真实日期，不新增虚构日期。

### 5.5 地图 `/map`

- 深灰低饱和底图、清晰地名；青蓝用于选中点；聚合点用数量与轮廓表达。
- 桌面：左侧作品/分组列表，中间地图，必要时右侧预览；工具条保持紧凑。
- 底部时间筛选独立一条；原有地图层、聚合抽屉、时间过滤能力都要纳入设计。
- 手机：地图占主视区，作品列表使用底部抽屉；打开抽屉时防止地图和列表争夺手势。
- 原有 MapLibre、GCJ02/WGS84 转换、聚合查询与 bbox 深链接保持现有契约；视觉迁移先于地图逻辑重构。
- 地图来源与署名保持可见；无 GPS 的内容在其他页面正常可见，地图空状态说明原因。
- 预览地图是明确标注的布局示意，不包含真实地图服务、地名、坐标或地图引擎。

### 5.6 搜索 `/search?q=...`

- 顶部自然语言输入框，下面为“全部 / 图片 / 视频”筛选与结果数量。
- 用作品画面、标题、类型和日期组织结果；相似度分数退为辅助信息，不像后台调试列表。
- 沿用现有文本向量搜索接口。输入、筛选与路由参数保持同步；失败、降级与零结果状态给出下一步操作。
- 手机筛选栏允许水平滚动；结果网格 2 列，窄屏可回退 1 列。
- 本轮预览只按演示标题/关键词本地筛选，不验证真实向量搜索。

### 5.7 登录、个人中心、分享

- 登录：延续照片背景，使用简洁访问面板；保留表单标签、校验、错误提示和 redirect 回跳。
- 个人中心：相同控件和档案排版，视觉简化；不增加后台管理功能。
- 分享页：轻量品牌头部、作品主视区、必要的分享说明；不要求访客理解复杂导航。
- 密码分享、过期、撤销、访问失败等状态统一设计；沿用已有访问控制与 token 行为。

## 6. 响应式与基础可用性

| 范围 | 布局约定 |
| --- | --- |
| ≥1200px | 12 列，宽幅首屏，详情图文并列，地图固定侧栏 |
| 768–1199px | 收紧侧边留白，减弱装饰编号，导航保持可用，卡片 2–3 列 |
| <768px | 图片名与向下入口靠底部同一行，下一行分段切换器与张数；主导航紧凑排列；内容区图文纵向；地图底部抽屉 |
| 360px 最小检查宽度 | 无页面横向溢出，标题不遮控件；主要触摸目标至少 44×44px |

普通正文对比度目标 4.5:1，大文字与关键控件至少 3:1。焦点清晰，装饰节点不进入读屏顺序；颜色配文字；所有主要行为不依赖 hover。参考：[W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[W3C 非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

使用 `100dvh` 处理需要满屏的区域；留意手机地址栏、安全区及横屏。普通内容页不要重新引入全局 body 滚动锁。

### 8.1 验证方式

- 构建：执行现有 `npm run build`（vue-tsc + Vite）。先记录基线，区分原有错误和新引入错误。
- 关键浏览流程：访客首页 → 精选详情 → 返回；搜索 → 类型筛选 → 详情；旅途 → 带参数地图；时间线 → 日期定位；登录 → 原页面；公开/密码/无效分享。
- 状态覆盖：加载、数据为空、单条内容、大量内容、长标题、缺图、接口失败、无 GPS、未登录。
- 响应式：360 / 390 / 768 / 1024 / 1440px；手机竖屏与横屏，键盘 Tab / Enter / Esc。
- 性能目标：先测基线，目标 LCP ≤2.5s、CLS ≤0.1、INP ≤200ms；这些是验收目标，不是当前实测结果。指标依据：[Web Vitals](https://web.dev/articles/vitals)。首屏图片建议桌面单张 ≤500KB、手机 ≤250KB，按实际画质调整。
- 普通页面延迟加载地图与非首屏播放器资源；图片固定尺寸或比例，避免布局跳动。
- 对滚动恢复、日期定位、地图 query 解析等实际改动的行为编写必要测试；纯颜色、边距变更不增加重复测试。

### 8.2 容易遗漏的点

1. 原 `App.vue` 的全局 overflow 和地图/时间线嵌套滚动，是布局迁移的主要回归风险。
2. 生产静态资源区分大小写；Windows 本地正常不代表部署正常。
3. 现有接口并不提供所有摄影元数据，不依靠补造字段完善版式。
4. 本地推荐区为空，概念稿效果不能代替真实数据、分享鉴权和播放器验证。
5. 地图浮层换样式时必须同时检查焦点、层级、事件穿透、归因署名和手机手势。
6. 先核实引用再清理旧主题、旧组件、旧动效依赖，避免误删仍在使用的能力。
