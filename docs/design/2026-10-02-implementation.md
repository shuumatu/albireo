## 验收方式与结果

- `npm run build`：Vue TypeScript 检查和 Vite 生产构建通过。
- `git diff --check`：通过。
- 正式入口 `http://localhost:5174/`：照片、图片名、倾斜选择器、张数与向下入口正常；接口不可用时各推荐区独立显示重试状态。
- 真实接口曾返回空列表，后续本地 9090 服务停止。因此有内容布局使用隔离的本地示例服务检查，没有向真实库补造内容。
- 首页：点击后名称/张数同步；Tab 聚焦第三项后显示 `03`；360px 选择器命中区均为 44×44px，无页面横向溢出；768px 与 1440px 首页已检查。鼠标 `pointerenter` 实现保留，自动化工具未模拟真实鼠标悬停。
- 图片详情：打开灯箱、Esc 关闭、焦点返回“全屏查看图片”按钮已验证；390px 详情纵向排版已检查。
- 时间线：示例数据三个月、36 项；月份选择可以定位到目标分组；修复原有跳转偏移、返回时清零和窄屏图片裁切问题；浏览位置缓存已检查。
- 地图：实际深色底图加载、390px 底部列表、署名和工具栏可见；方向键把起始范围从 0 调整到 1；没有真实时间范围时不显示虚构日期轴。
- 搜索：示例数据“雪山”搜索、视频筛选后 URL 含 `type=video`、结果减少为 1 条、进入视频详情正常；390px 两列排版已检查。
- 登录：空表单校验、登录/注册模式切换与手机排版已检查，没有提交真实账号或修改密码。
- 分享：隔离密码页进入合集、键盘打开图片预览、过期提示和返回首页已检查；修复合集卡片残留白底。
- 示例环境检查期间无 Vue 运行错误；过期分享的预期 HTTP 404 与真实后端不可用的网络错误不属于前端脚本故障。

仍需真实环境验证的业务：账号登录后的资料和密码修改、评论写入/删除/点赞、受保护分享鉴权、实际视频流播放与清晰度切换、真实聚合数据和旅途 bbox 的端到端结果。相关实现保留，未将示例测试当作真实服务验收。

## 资源与性能

- 首页全景恢复五张原始照片：高 2160px、宽 5092–12963px，单张约 1.63–5.63 MB。首屏只请求当前照片，其他照片选择时加载、解码后交叉淡入；避免把按整图宽度压缩的缩略图放大铺满首屏。登录页继续使用轻量 WebP 背景。
- Naive UI 改为页面按需导入；地图、视频、时间线等路由懒加载。首页主 JavaScript 包从本轮初次构建约 2.22 MB 降至约 469 KB（gzip 约 153 KB）。
- 地图约 1.16 MB、视频约 718 KB，按路由加载，仍有 Vite 大包提示。没有把 chunk 提示隐藏。
- 系统减少动态效果偏好应用到 CSS、首屏渐变和地图标记动效。
- LCP / CLS / INP 仍为设计目标，未做生产网络环境的 Web Vitals 实测。

## 可复现的隔离布局验收

```powershell
cd F:\code\vue\albireo
node tests/visual-preview.mjs
```

访问 `http://127.0.0.1:5180/`。该服务使用同一套正式 Vue 组件，页面左下角标明示例数据；仅运行时覆盖 API 地址，不改变 `.env`、数据库或生产构建。未实现的写入接口统一拒绝。

测试入口包括 `/`、`/timeline`、`/map`、`/search`、`/image/preview-2`、`/video/preview-6`、`/s/locked`、`/s/expired`。视频示例没有播放源，只用于检查缺少可播放版本的状态。正式 API 默认仍为 `http://localhost:9090`，可通过 `VITE_API_BASE_URL` 配置部署地址。

## 截图

### 时间线接排与比例修复（2026-10-02）

- 去掉每个日期强制独占整行的样式。按原顺序逐张排布，下一天的作品能放下就接在同一行；同一天跨行时，在新行重复日期，保持归属清晰。
- 去掉 100–400px 宽度限制及手机端伸缩铺满规则。照片、视频封面统一读取实际尺寸，按比例计算宽高；超宽素材整体缩小到容器宽度，使用 contain 防止裁切。尺寸按 URL 缓存，月份数据更新时不再恢复成正方形。
- 删除 CHRONICLE、大标题及 ARCHIVE 编号，改为 44px 单行工具栏，保留小号“时间线”、数量及月份选择。日期标题与图片间距收紧。
- 分组拆成行片段后，滚动锚点保留片段标识；月份跳转仍按该月首个片段定位。右侧时间刻度按共享行的实际高度分配，避免重复累计整行高度。
- `node --test tests/timeline-layout.test.mjs`：4 项测试通过，覆盖跨日同行、长日期分组换行后接排、横竖及超宽素材比例、窄屏无溢出、未加载月份顺序。TypeScript、生产构建及 `git diff --check` 通过；原有大 chunk 提示仍存在。
- 验收开始时真实首页接口失败，最后正式时间线返回 0 项。因此使用隔离服务的有标记尺寸素材进行有内容布局验收：1440px 首行包含五个日期，照片和竖版视频显示比例与素材比例一致；390px 无横向溢出、月份工具栏仍为 44px；月份跳转定位正确，离开后返回保留滚动位置；未见浏览器脚本错误。正式时间线空状态也已确认。

### 首页全景交互补充（2026-10-02）

- 鼠标在左右各 30% 区域持续平移画面，进入区域即有可见速度，越靠边越快；中间 40%、按钮和链接、离开首屏、窗口失焦或切换页面时停止。图片名与底栏留白不再屏蔽平移。两端限制在原图边界，不露空白。
- 位移按经过时间计算，适配不同刷新率；图片统一从中间位置展示，切图保留当前浏览位置。图片获得键盘焦点后，左右方向键也可以移动。
- 保留图片名称、倾斜选择器、当前张数及 SCROLL TO EXPLORE。首屏独立使用原先五张全景，推荐区仍使用业务接口。
- `node --test tests/panorama.test.mjs`：4 项测试通过，覆盖中间静止、边缘方向与速度、不同刷新率一致性、边界、无横向溢出的图片，以及首帧零时间差、持续运行、停止和反向重启。修复首帧 RAF 时间戳早于启动时刻导致动画直接退出的问题，改为使用 RAF 自身时间基准。
- 两侧箭头简化为浅青色细线折角，去掉斜切底片、横杆及 PAN / END 文字；垂直居中，进入边缘时淡入，离开时隐藏，到达边界降低透明度。装饰不拦截鼠标，平移逻辑保持不变。
- 浏览器确认首张为 8731×2160、第四张为 12963×2160，切换后名称和张数同步；方向键将实际图片位置从 50% 调整至 55%。本次通过浏览器坐标操作验证鼠标进入左侧持续移动至 0%、右侧反向移动、中央停止在 9.7786% 并保持不变，箭头随区域正确显示和隐藏。
- TypeScript 与生产构建通过；本机首次构建遇到内存不足，限制 Node 堆及新生代大小后完成。已有地图、视频 chunk 大小提示仍保留。
