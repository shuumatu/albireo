# 地图初始化诊断

用户反馈的“地图暂时无法加载”来自 Map.vue 的初始化 catch，与“作品暂时无法加载”的接口或渲染数据错误分开。历史异常的原始堆栈没有保留；当前检查未复现，不能确定当时根因，也不能声称已修复历史故障。

本次改动：

- 底图样式请求检查 HTTP 状态、JSON 及基本样式结构，12 秒超时后取消请求，显示明确的可重试提示。
- 根据失败阶段区分样式读取、地图渲染器创建及其余初始化错误；WebGL 创建失败有独立提示。
- 初始化期间阻止重复重试和底图切换，旧地图移除后清空引用。
- 监听图形上下文丢失及恢复，显示中断提示，恢复时清除提示并调整尺寸。
- 控制台保留原始异常并标记初始化阶段；没有更改地图服务、密钥或浏览器设置。

验证：4 项 map-loading 测试通过，覆盖 HTTP 404、HTML 回退、无效样式、正常样式、超时取消、网络错误、渲染失败分类；TypeScript 与 Vite 生产构建通过，已有地图及视频大包提示仍保留；git diff --check 通过。浏览器验证初始化、选择浅色底图、离开后重新进入地图，无初始化失败提示。未通过浏览器强制制造 WebGL 故障，因此上下文恢复只完成实现检查。
