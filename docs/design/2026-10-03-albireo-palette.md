# ALBIREO 黄蓝双色配色落地

日期：2026-10-03。范围：访客端 `albireo`。

## 灵感与方向

Albireo（辇道增七）的视觉特征是金黄与蓝色的鲜明并置。NASA 对 Albireo A、B 的介绍分别描述了较冷的 K 型巨星与较热的蓝色主序星。这次提取的是它们的冷暖关系，下面的色值是适配屏幕和界面可读性的设计选择，不是恒星颜色的精确测量值。

- 用户参考：[维基百科：輦道增七](https://zh.wikipedia.org/wiki/%E8%BC%A6%E9%81%93%E5%A2%9E%E4%B8%83)
- 主要依据：[NASA：Beautiful Albireo AB](https://science.nasa.gov/image-article/apod-2022-february-24-beautiful-albireo-ab/)
- 补充参考：[NASA：Seeing Double](https://science.nasa.gov/solar-system/skywatching/night-sky-network/aug2024-night-sky-notes/)

保留现有摄影档案的版式和简洁 HUD，以深蓝灰为大面积底色，金黄与星蓝只承担小面积视觉重点。浅色精选区使用暖纸色，形成从深色首屏到内容区的自然过渡。

## 配色与职责

| 颜色 | 色值 | 主要用途 |
| --- | --- | --- |
| 恒星金 | `#E8BC72` | 品牌 A、章节、当前张数、主要操作按钮、照片类型、重要计数 |
| 高亮金 | `#F4D8A3` | 金色按钮悬停、图片上的小标签 |
| 星蓝 | `#80B5F4` | 交互提示、输入聚焦、链接、进度、视频类型、HUD 对角 |
| 高亮蓝 | `#ABCDF8` | 蓝色交互悬停、图片上的视频与方向图标 |
| 夜空底色 | `#10151F` | 页面背景、按钮深色文字 |
| 面板 | `#192332` | 表单、详情、地图工具区域 |
| 抬升面板 | `#223047` | 菜单、局部层次 |
| 正文 | `#F1EEE6` | 标题和主要内容 |
| 次要文字 | `#A8B4C8` | 元信息、说明 |
| 暖纸色 | `#F0EADC` | 首页精选与旅途区 |
| 浅底深金 | `#80591D` | 浅色区域的金色小字、章节和标记 |
| 浅底深蓝 | `#2C6097` | 浅色区域的蓝色链接与装饰 |

金、蓝的弱背景均为对应色的 14% 透明度。正文保持中性色，错误与成功继续保留语义红、绿；媒体类型同时保留图标、文字和按钮选中状态。

## 页面改动

| 页面 / 部件 | 实际改动 |
| --- | --- |
| 导航、页脚、favicon | 金色 A / 品牌字、蓝色斜线；当前导航为金色，底部用金线和蓝色短点组合，悬停为蓝色 |
| 首页首屏 | 倾斜选择器使用蓝色主体与金色细线；当前张数金色；图片名、总张数和向下入口保持简洁；左右箭头使用接近白色的淡蓝，保证照片上可见 |
| 精选与旅途 | 暖纸色背景、深金章节、深蓝链接；圆形章节装饰分别使用蓝色数字和金色弧线；旅途主按钮金色 |
| 媒体卡片 | 照片标题点金色、视频标题点蓝色；悬停 HUD 左上金、右下蓝；视频标识蓝色 |
| 时间线 | 金色数量与年份、蓝色月份点和滚动位置；图片及视频封面保留原比例；顶栏保持 44px |
| 地图 | 浮层统一深蓝灰；照片徽标与聚合数量金色，视频徽标蓝色；筛选、范围、密度图和工具交互蓝色 |
| 图片 / 视频详情 | 金色章节与 HUD 左上角、蓝色脚注与 HUD 右下角；信息层级保持中性正文 |
| 搜索 / 相似内容 | 金色搜索按钮；输入聚焦和类型选择蓝色；相关性标记结合文案使用黄蓝区分 |
| 登录 / 分享 | 小尺寸黄蓝双星标记、金色主按钮、蓝色次级链接；登录背景加入克制的双色柔光 |
| 评论 / 个人中心 | 主操作与计数金色，头像和聚焦蓝色；账户操作逻辑不变 |
| 视频播放器 | 金色主播放按钮，蓝色播放 / 音量进度；菜单选中金色、悬停蓝色，画布保持黑色 |

保留首页悬停切换、全景边缘平移、简约箭头、SCROLL TO EXPLORE；保留时间线跨日期同行排布、媒体比例、月份选择与滚动定位。

## 实现入口

- `src/styles/archive.css`：全局设计变量、主按钮、双色 HUD。
- `src/theme/archive.ts`：Naive UI 的表单、弹层、选中及禁用状态；普通交互蓝色、实心主按钮金色。
- `src/views/mainPage.vue`：浅色内容区的深金 / 深蓝局部变量。
- `src/views/map/mapTokens.css`：地图与全局变量共用同一套颜色。
- `src/views/map/MapTimeline.vue`：Canvas 读取已解析的轨道颜色，避免图表遗留旧强调色。

后续调整优先从主题变量修改；浅色区文字使用 `--accent` / `--accent-warm`，需要固定浅金或浅蓝填充时使用 `--star-*`。

## 验证

以 sRGB 相对亮度计算静态颜色对比度：

| 组合 | 对比度 |
| --- | --- |
| 金色 / 夜空底色（也即主按钮深色字 / 金底） | 10.33:1 |
| 蓝色 / 夜空底色 | 8.56:1 |
| 金色 / 深色面板 | 8.94:1 |
| 蓝色 / 深色面板 | 7.41:1 |
| 次要文字 / 深色面板 | 7.55:1 |
| 深金 / 暖纸色 | 5.20:1 |
| 深蓝 / 暖纸色 | 5.43:1 |
| 浅区次要文字 / 暖纸色 | 5.00:1 |
| 浅区次要文字 / 浅色面板 | 4.56:1 |

以上检查针对列出的不透明色对，不等同于全站无障碍认证；照片上文字仍使用原有底部遮罩与文字阴影。

- `npm run build`：TypeScript 与生产构建通过；仍有地图和视频依赖块超过 500 kB 的体积提示。
- 现有 12 项测试通过：全景平移 4 项、时间线布局 4 项、地图加载与错误分类 4 项。
- 浏览器实页检查：首页、浅色精选区、地图、时间线、登录、搜索、图片详情、视频未就绪状态、分享密码页。
