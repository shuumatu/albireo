# 时间轴柔焦显影

照片和视频封面共用 `TimelineMedia.vue`。真实小缩略图加载后作为模糊底层，显示图解码完成后以 320ms 透明度、360ms 清晰度过渡显现。等待时用 2.4s 低对比度呼吸；日期、视频标识和卡片尺寸保持稳定。

## 数据与兼容

- 时间轴桶增加可选 `thumbnailUrl`、`width`、`height`。后端从已有 `media_image_files` 和封面图片记录读取，不新增表、迁移或图片处理任务。
- 视频使用封面图片宽高，不能使用可能不同比例的视频流宽高；现有封面可见性过滤继续作用于预览与尺寸。
- 缩略图与显示图同地址时不创建重复预览。没有独立缩略图的历史记录先用柔和底色；缺少宽高时保留原有加载后测量逻辑，仍可能重排。
- 需要构建并重启 metadata-service 才能返回新增字段；旧接口仍兼容，但只有底色占位和最终淡入。

## 交互

- 距滚动视口 240px 内才开始图片请求，屏外／KeepAlive 隐藏时停止呼吸与慢网计时。
- 图片下载与解码完成后独立显现，不人为延迟快请求。最近 500 个已解码地址不重复显影。
- 等待 3s 后显示“仍在加载”；失败停止动画，显示独立重试按钮，点击重试不会打开详情。没有封面时显示“暂无封面”。
- 预览下载失败不会阻塞显示图。遵循 `prefers-reduced-motion`，禁用呼吸和显影过渡。

## 验证

- `npm run build` 通过，保留原有地图／视频大包提示；最终 TypeScript 检查通过。
- Playwright：桌面、Pixel 7、减少动态效果三个环境，共 15 项通过。覆盖预览、慢网、比例与位置稳定、视频入口、返回页面、失败重试、旧数据、重复地址和屏外加载。
- 4 项既有时间轴排版测试通过。
- 后端在新建且完整迁移的临时 PostgreSQL 数据库上执行 3 项时间轴专项测试，验证尺寸、缩略图、封面可见性与数量，全部通过；测试数据库随后删除。
- 尝试执行整组 `PostgresVisibilityTest` 时，另有 3 项现有测试失败：集合 `TIMESTAMPTZ` 到 `LocalDateTime` 的映射（2 项），以及空测试库缺少 `user_id=1`（1 项）。这些失败不属于时间轴修改。
